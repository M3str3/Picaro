# Measurement reports

These reports are point-in-time snapshots from the phase they describe, not a
description of the current tree. The configs named inside were the ones in use
at that moment; they have since been consolidated into the curated set under
`examples/configs/` (with CI-only fixtures in `tests/configs/`), so a filename
in an older report may no longer exist.

Each report embeds or abridges the YAML it used, so the measurements stay
reproducible from the report alone even after the configs move.

When adding a new EDR report, start from `template.md`.
