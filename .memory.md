## Next step

- **M4, if ever wanted:** x86 indirect syscalls need a Heaven's Gate thunk plus
  64-bit SSN resolution (a redesign, not a flag). `syscalls.mode: indirect` and
  `api_resolution` stay x64-only and are rejected on x86.
- **TLS callbacks under hollowing.** A callback needs a thread, and a
  never-started thread has no TLS array in its TEB (writing its slot faults the
  target). Options: run them on the main thread parked on a `jmp $` stub between
  calls, or build the callback thread's TLS array from the main thread's entries.
- **TLS index collisions.** `TlsAlloc` hands out the lowest free index, which can
